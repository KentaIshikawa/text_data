戻り値について

関数の処理の中で、return を書く事で、関数の中で処理した内容を、関数を実行した場所に戻す事ができる。
returnは、「値を戻す」だけでなく「プログラムを止める」という意味もある為、通常関数の処理の中の最後に書かれる事が多い。

const modorichi = (onamae) => {
    const result = onamae + 'さま';
    return result;
}
const onamae01 = modorichi('鈴木');
console.log(onamae01);
const onamae02 = modorichi('佐藤');
console.log(onamae02);



//0埋め（0パディング）
const add_zero = (num) => {
    const result_zero = '0' + num;
    const result_slice = result_zero.slice(-2);
    return result_slice;
}
//今日の日付
const today = new Date();

const month = today.getMonth() + 1;
const month_zero = add_zero(month);
const date = today.getDate();
const date_zero = add_zero(date);

console.log('今日は、' + month_zero + '月' + date_zero + '日');
